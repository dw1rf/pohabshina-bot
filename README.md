Многофункциональный Discord-бот для сообщества: модерация, тюрьма, уровни,
репутация, экономика, RP, музыка, AI-NPC, фильмы, питомцы, клубы, события,
тикеты и автоматические публикации. Бот работает на `discord.py 2.x`, хранит
состояние в SQLite и разворачивается на BotHost через Docker.

Видимый бренд — **Vulgarities Bot**. Техническое имя репозитория и GHCR-образа
сохранено для совместимости с действующим развёртыванием.

## Текущая версия

- `35` загружаемых модулей Discord;
- Python `3.11`;
- SQLite в WAL-режиме с автоматическими миграциями;
- Docker-окружение с `ffmpeg`, `ffprobe`, `deno`, `libopus0` и актуальным DAVE-голосом Discord;
- восстановление persistent-кнопок, активных тюрем, розыгрышей и задач после
  перезапуска;
- регрессионный набор: `111` тестов.

## Основные возможности

### Модерация и сервер

- `/warn`, `/warnings`, `/clearwarns`, `/mute`, `/unmute`, `/ban`, `/unban`,
  `/kick`;
- `/jail` и `/unjail`: отдельный приватный канал, роль заключённого,
  восстановление срока после рестарта, кнопки подачи апелляции и просмотра
  оставшегося времени;
- reaction roles, запрет реакций, защита от повторных упоминаний, automod и
  raid guard;
- `/support_panel` и `/shop_panel` с persistent-интерфейсом тикетов;
- `/say`, `/say_embed`, `/say_afisha` для публикаций от имени бота.

### Репутация, уровни и профили

- `+реп`, `-реп`, `+rep`, `-rep` ответом на сообщение или сразу после сообщения
  участника;
- после изменения репутации бот добавляет актуальный знак и число в начало
  серверного никнейма, не изменяя основную часть имени: `+18 username` или
  `-3 username`;
- лимит выдачи репутации — два раза за 24 часа от одного участника;
- `/rank`, `/top`, `/profile`, `/profile_user`, достижения, коллекции, сезоны и
  серверные задания;
- фоновые обработчики не конкурируют с командой репутации за запись в SQLite;
  кратковременная блокировка базы обрабатывается повторной попыткой.

### RP и NSFW

- более 60 SFW-действий через `/rp act` и отдельные slash-команды;
- NSFW-команды работают только в Discord-канале с включённой отметкой `18+`;
- администратор выбирает единственный NSFW-канал командой
  `/set_nsfw_channel`;
- `/set_nsfw_import_channel` задаёт отдельный 18+ импорт-канал: сообщения и
  Discord-пересылки из него бот повторно публикует от своего имени в выбранный
  NSFW-канал, не допуская циклов и повторной отправки;
- `/bot_settings` показывает текущие NSFW-канал, импорт-канал и параметры
  социальных модулей;
- телеметрия RP не может превратить уже показанное действие в ошибку команды.

### Развлечения и игровые системы

- фильмы и сериалы через Watchmode;
- серверная экономика, банк, магазин, рынок, задания и сезонные события;
- питомцы, PvE/PvP, рейды, эволюция и экипировка;
- клубы, сообщества и недельные клубные войны;
- starboard, розыгрыши, предложения, еженедельный дайджест и AniList feed;
- дни рождения и автоматические утренние/ночные сообщения;
- TTS и музыкальный модуль с очередью, autoplay и источниками YouTube,
  Spotify и Яндекс Музыка.

### AI-NPC

- провайдеры Gemini, Groq или локальный Ollama;
- включение AI отдельно для выбранных каналов;
- локальная память, отношения к участникам, mood сервера, cooldown и дневные
  лимиты;
- очистка invite-ссылок, email, телефонов и token-like строк перед сохранением;
- AI не получает права модератора и не выполняет реальные наказания.

## Быстрый локальный запуск

Требования:

- Python `3.11`;
- `ffmpeg`, `ffprobe` и `deno` в `PATH` для музыки и TTS;
- Discord application с включёнными нужными privileged intents.

```bash
python -m venv .venv
```

Активация на Windows:

```powershell
.venv\Scripts\Activate.ps1
```

Установка и запуск:

```bash
python -m pip install -r requirements.txt
python bot.py
```

Перед запуском скопируйте `.env.example` в `.env` и заполните как минимум:

```env
DISCORD_TOKEN=
WATCHMODE_API_KEY=
SQLITE_PATH=data/bot.db
LOG_LEVEL=INFO
```

Не публикуйте `.env`, Discord token, API-ключи, cookie-файлы и дампы базы.

## Основная конфигурация

| Переменная | Назначение |
| --- | --- |
| `DISCORD_TOKEN` | Токен Discord-бота. Обязателен. |
| `WATCHMODE_API_KEY` | API-ключ фильмов. Обязателен текущей конфигурацией запуска. |
| `SQLITE_PATH` | Основная база, по умолчанию `data/bot.db`. |
| `MOD_LOG_CHANNEL_ID` | Канал модераторских логов и jail-апелляций. |
| `SUPPORT_CATEGORY_ID` | Категория приватных support-тикетов. |
| `SUPPORT_ADMIN_ROLE_ID` | Роль сотрудников поддержки. |
| `BIRTHDAY_CHANNEL_ID` | Канал поздравлений с днём рождения. |
| `TIMEZONE` | Часовой пояс расписаний, обычно `Europe/Moscow`. |
| `FFMPEG_EXECUTABLE` | Необязательный нестандартный путь к `ffmpeg`. |
| `YTDLP_COOKIE_FILE` | Путь к cookie-файлу YouTube внутри контейнера. |
| `AI_PROVIDER` | `gemini`, `groq` или `ollama`. |
| `AI_ENABLE_MEMORY` | Включает очищенную AI-память. |
| `AI_DAILY_LIMIT` | Суточный лимит AI-запросов на сервер. |

Полный список безопасных шаблонных значений находится в `.env.example`.

## Docker и BotHost

Основной контейнер собирается из `Dockerfile` и запускает:

```text
python -u bot.py
```

Для Pterodactyl доступен образ:

```text
ghcr.io/dw1rf/pohabshina-bot:pterodactyl-voice
```

Если хостинг игнорирует репозиторный Dockerfile, используйте этот образ и
startup command `python -u bot.py`. Дополнительная инструкция находится в
`docs/pterodactyl-voice-image.md`.

Признаки корректного голосового окружения в журнале:

```text
ffmpeg found: path=...
ffprobe found: path=...
deno found: path=...
PyNaCl is installed; Discord voice support can load.
davey is installed; Discord DAVE voice support can load.
```

## Данные и устойчивость

- основная база: `data/bot.db`;
- отдельная база свадеб: `weddings.db`;
- перед изменениями схемы создаются резервные копии;
- таблицы и недостающие столбцы создаются автоматически;
- SQLite использует `WAL` и `busy_timeout`;
- чувствительные файлы и рабочие базы не должны попадать в Git.

## Проверка изменений

```bash
python -m pytest -q
python -m compileall -q bot.py bot_client.py cogs services tests utils
python -m pip check
```

Успешные локальные тесты не подтверждают работу уже запущенного контейнера.
После публикации нужно отдельно дождаться сборки GitHub, обновления BotHost и
строки свежего запуска в рабочих логах.

## Структура проекта

```text
cogs/          Discord-команды и обработчики событий
services/      бизнес-логика, SQLite и внешние провайдеры

catalog_data/  локальные каталоги контента
assets/        изображения и медиа проекта
tests/         регрессионные тесты
bot.py         точка запуска
bot_client.py  инициализация бота, баз и модулей
```
